Spectral            SIL Open Font License 1.1  -> LICENSE-Spectral.txt
                    Production Type
JetBrains Mono      SIL Open Font License 1.1  -> LICENSE-JetBrainsMono.txt
                    JetBrains s.r.o.
                    Im Build als Subset ausgeliefert (Versal-Labels, Ziffern,
                    Interpunktion, deutsche Umlaute) - 3.440 Bytes statt 90,2 KB.

Inter Tight         SIL Open Font License 1.1, ueber @fontsource eingebunden.
                    Steht hier als STAND-IN fuer Suisse Intl (Swiss Typefaces,
                    kommerziell lizenziert). Die Suisse-Dateien sind nicht Teil
                    dieses Repositoriums.

Die OFL verlangt, dass diese Lizenztexte mit den Schriftdateien zusammen
weitergegeben werden. Deshalb liegen sie in public/ und nicht in src/assets/ -
Vite kopiert public/ unveraendert nach dist/, waehrend src/assets/ nur das
enthaelt, was auch importiert wird.
